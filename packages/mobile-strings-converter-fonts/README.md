# Mobile Strings Converter Fonts

Fonts used by [mobile-strings-converter](https://pypi.org/project/mobile-strings-converter/) to write PDF files. They live in their own package so that only the projects that write PDF files download them. Install them with the `pdf` extra:

```sh
pip install 'mobile-strings-converter[pdf]'
```

The fonts belong to their authors and are distributed under their own licenses.
